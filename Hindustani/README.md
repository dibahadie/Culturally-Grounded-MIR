# Hindustani Music Information Retrieval & Generation Paper Collection

A curated, comprehensive collection of research papers, datasets, and computational resources for the analysis, recognition, and generative modeling of North Indian (Hindustani) Classical music.

## 📖 Overview
Hindustani music is built upon the *Raga* melodic framework and *Tala* rhythmic cycles, characterized by continuous pitch glides (*Meend*), microtonal inflections (*Shruti*), and extended unmetered improvisations (*Alap*). Because Tonic (*Sa*) is relative rather than fixed to an absolute pitch, standard Western MIR algorithms require substantial adaptation. This repository serves as a central hub for researchers to find papers and datasets.

## 🗄 Datasets & Corpora

| Dataset | Type | Description | Link |
| :--- | :--- | :--- | :--- |
| **Saraga (Hindustani)** | Audio/Annotations | Open dataset of Hindustani art music recordings with time-aligned tonic, pitch, rhythm, and structural annotations by CompMusic. | [MTG Github](https://mtg.github.io/saraga/) |
| **Dunya Hindustani** | Audio/Metadata | A web-based corpus exploration tool and audio collection by CompMusic. | [Dunya Portal](https://dunya.compmusic.upf.edu/hindustani/) |
